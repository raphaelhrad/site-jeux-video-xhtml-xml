# Nos jeux vidéo préférés - Site Web XHTML & XML
## Auteurs : Cloé BIRINGER & Raphaël HERAUD

Site web dédié à une sélection de jeux vidéo créé dans le cadre d'un projet universitaire de développement web.

Le projet utilise les standards du web (XHTML, CSS3, TypeScript)
et contient aussi la modélisation et la transformation de données structurées (XML, DTD, XSLT).
