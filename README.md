# Nos jeux vidéo préférés - Site Web XTHML & XML
## Auteurs : Cloé BIRINGER et Raphaël HERAUD

Site web dédié à une sélection de jeux vidéo (Dofus, Life is Strange, Mario Kart 8 Deluxe et Tomodachi Life). Projet universitaire dédié au développement web et à la structuration de données.

Ce projet utilise XHTML, CSS et TypeScript, ainsi que la modélisation de données structurées via XML, DTD et XSL.
